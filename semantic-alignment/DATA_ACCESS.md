# Data access boundary

This package redistributes no VitalDB, MOVER or INSPIRE records, source-text
collections, patient/surgery/term-level derivatives or terminology artifacts.
Users obtain access independently and follow the original resource terms.

Excluded: source/processed rows; real identifiers and split lists; full mappings,
review rows, cluster members/dictionaries, RF2, model weights, embeddings/indices,
RAG requests/responses/logs and real-data predictions or neighbors.

No aggregate-result CSVs are included in this module. Published tables and
figures provide the paper evidence. Configuration interfaces and restricted-file
hashes do not grant access or redistribution rights to the underlying materials.

Access channels: [VitalDB](https://vitaldb.net/),
[MOVER](https://archive.ics.uci.edu/dataset/877/mover-medical-informatics-operating-room-vitals-and-events-repository),
[INSPIRE](https://physionet.org/content/inspire/),
[SNOMED International](https://www.snomed.org/get-snomed).
Obtain the required permissions before accessing or using each resource.
